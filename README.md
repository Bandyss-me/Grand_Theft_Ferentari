This is a game reprezenting an average day in romania. Glory to Romania!!!
Btw this is a collab with @sarmiswilldoit.
You are In Bucharest, Romania (Ferentari) and your job is to steal.
You only have a car with which you can escape from the police.
Note that this game is in beta. I am planning to release it in August.
For now, I only have a functioning Dacia Logan and a police car that uses Djikstra's algorithm for pathfinding.
During developing, I used a little AI to help me simulate physics for the car. So far, I enjoyed making this game.
